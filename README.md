# RajCode Portfolio

Personal developer portfolio for Rajesh Patra, featuring shipped projects, technical skills, education, achievements, and contact information.

Live site: <https://rajcode-portfolio.netlify.app/>

## Features

- Responsive portfolio layout for desktop and mobile
- Project search and category filtering
- Project detail modal with demo and source links
- Interactive portrait and ASCII art modes
- GitHub repository count fetched from the GitHub API
- Contact form powered by Web3Forms
- Social profile links and downloadable resume
- Ambient Matrix-style canvas animation

## Run Locally

This is a static HTML project and does not require a build step.

1. Open `index.html` directly in a browser, or serve the folder with a local web server.
2. Keep the referenced assets, including `logo.png`, `image.jpg`, and `rajesh_patra_resume.pdf`, in the project folder.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Technologies

- HTML5
- Tailwind CSS CDN
- JavaScript
- Font Awesome
- Google Fonts
- Web3Forms
- GitHub REST API

## Deployment

The project can be deployed to any static hosting provider, including GitHub Pages, Netlify, or Vercel. Upload the project files and configure the site to use `index.html` as the entry page.
